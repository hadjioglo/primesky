# Playwright + Cucumber + Java Project

This project is a starter template for automated testing using Java, Playwright, Cucumber, and Maven.

## Features
- Java 21 (LTS)
- Playwright for browser automation
- Cucumber for BDD
- Maven for build and dependency management

## Getting Started

1. **Install Java 21**
2. **Install Maven**
3. **Build the project:**
   ```sh
   mvn clean install
   ```
4. **Run tests:**
   ```sh
   mvn test
   ```

## Project Structure
- `src/main/java` - Application code (if needed)
- `src/test/java` - Test code (Cucumber step definitions, runners)
- `src/test/resources` - Feature files

## Dependencies
- [Playwright for Java](https://playwright.dev/java/)
- [Cucumber JVM](https://cucumber.io/docs/guides/10-minute-tutorial-java/)
